The Backrooms builder is an editor-friendly level assembly tool for quickly blocking out yellow-room levels with gameplay markers.

The geometry slots (`floor_scene`, `wall_scene`, `ceiling_scene`, `light_scene`, and `low_barrier_scene`) are exported `PackedScene` resources. Leave their defaults for Backrooms or assign another compatible 4 m kit, as demonstrated by the Endless House builder.

Each kit scene root owns its authored local transform. The builder adds the cell's grid translation to that transform; it does not replace the root position. Keep vertical placement in the kit scene itself: the current Backrooms floor root is at y = -0.1 m, walls are centered at y = 2.1 m, ceilings are at y = 4.12 m, and low barriers are at y = 0.575 m. Do not pre-apply the grid x/z position inside a kit scene.

| --- | --- |

| `D` | Floor, ceiling, and generated Match Dots note |
| `Q` | Floor, ceiling, and generated Sequence Lock note |
| `K` | Floor, ceiling, and generated Code Lock note |
| `O` | Floor, ceiling, and generated Polarity Switch note |
| `W` | Floor, ceiling, and watcher monster |
| `C` | Floor, ceiling, and sprint-hearing chaser monster |
| `A` | Floor, ceiling, and late-activating ambush chaser |
| `M` | Floor, ceiling, and False Door |
| `U` | Floor, ceiling, and The Unlit monster |
| `B` | Floor, ceiling, and low barrier/cover |
| `P` | Floor, ceiling, and solo-friendly latch-once pressure plate |
| `H` | Floor, ceiling, and one-player hold switch pressure plate |
| `G` | Floor, ceiling, and two-player group hold switch pressure plate |
| `R` | Floor, ceiling, one-player hold switch, and pressure-powered work light |
| `T` | Floor, ceiling, and one-shot breaker outage trigger |

Generated content is grouped under `GeneratedBackrooms` as `Geometry`, `Markers`, `Mechanics`, `Notes`, and `Monsters`.

`P` pressure plates are latch-once by default, so they are compatible with solo local testing. Use `H` for a true one-player hold switch and `G` for a two-player hold switch when a co-op gate should stay open only while players stand on it.

The reusable chaser generated by `C` starts dormant, activates after the first collected note, patrols a small area when it has no target, and triggers a short threat cue. The builder exposes its base speed and sprint multiplier under `Threats`; the demo keeps its early sprint response below the player's running speed.

The ambush chaser generated by `A` is slightly faster, hears sprinting farther away, and activates after the configured collected-note threshold. Its builder speed controls are separate from the regular chaser. Use it sparingly so a Backrooms level escalates instead of becoming constant pursuit.

Generated `N` notes default to the Polarity Switch puzzle. Use `D`, `Q`, `K`, and `O` when a layout should force a specific puzzle type without changing the builder-wide default.

Assign `EvidenceProfile` resources to the builder's four puzzle slots when generated records need distinct recovered text or journal facts/rumors. Unassigned slots continue to use `generated_note_text`, so prototype layouts do not require extra resources.

`U` is production-capable and is already used by The Unlit Maintenance Wing. Its evidence loop, synchronized mechanic/creature state, Restart/late-join behavior, and server-authoritative production integration are complete in that encounter. During visual-upgrade work, preserve the generated `U` gameplay root/path and replace only its visual children/material presentation unless mechanic changes are explicitly requested.

`R` and `T` provide the matching editor-native encounter wiring. Each `R` work light binds to the pressure plate generated in its own cell and aims at the nearest generated `U`. Each `T` binds to the nearest generated work light. The `work_light_range` inspector property controls all generated work lights in that builder. Use spatial separation when a layout contains several independent Unlit encounters so nearest-node wiring stays unambiguous.

The paired-Unlit smoke creates two separated `R/U/T` clusters and verifies that either breaker can suppress and recover its own light without changing the other creature's state.

The `BackroomsBuilder` node also reports Godot Inspector configuration warnings before play. It flags empty or uneven layouts, unsupported symbols, missing spawn/exit markers, `T` without any `R`, `R` without a `U` aiming target, and equal-distance `R/U` or `T/R` bindings. These warnings do not change runtime generation; they make authored layout mistakes visible in the editor.

## Workflow

1. Create or duplicate a Backrooms level scene.
2. Add a `Node3D` with `BackroomsBuilder`.
3. Edit the multiline `layout` string in the inspector.
4. Keep `rebuild_in_editor` enabled while blocking out the map.
5. Use `N`, `W`, and `C` sparingly; the level should remain readable and not overloaded.
6. Check wall, ceiling, and cover root heights in the generated editor preview after replacing a kit scene.
7. Run a local scene smoke check before using the level in `Main`.

For old-house rooms using the same generation code, see `docs/endless_house_builder.md`.
